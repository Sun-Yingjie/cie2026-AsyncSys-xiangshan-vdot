## 5. VCS 编译 MinimalConfig
- 手动加载 VCS：VCS_HOME=/mnt/edatools/synopsys/vcs/V-2023.12-SP1，PATH 前置 bin，SNPSLMD_LICENSE_FILE=28001@lzdx01。
- 命令：make simv CONFIG=MinimalConfig NUM_CORES=1
- 坑1：mill 阶段成功生成 build/rtl（~1.1GB 分片 SV），但 VCS 报 `Cannot find cell in liblist: array_*_ext`。
  根因：scripts/gen_sep_mem.sh 调 vlsi_mem_gen 时 `python3` 被 Mentor Calibre 锁定环境抢占（VCO=aok vs aoi 报错），25 个 *_ext.v 未生成。
  解法：建 $HOME/.local/syspy/python3 -> /usr/bin/python3（Python 3.6.8），PATH 前置重跑；25 个 *_ext.v 全部生成。
- 坑2：C++ testbench 缺 zstd.h（无 sudo 无法装 dev 包）。
  解法：make 加 NO_ZSTD_COMPRESSION=1。
- 坑3：C++ testbench 缺 sqlite3.h（chisel_db.cpp/perfCCT.cpp）。
  解法：make 加 WITH_CHISELDB=0 WITH_CONSTANTIN=0（hello Difftest 不需要性能 DB）。
- 最终命令：make simv CONFIG=MinimalConfig NUM_CORES=1 NO_ZSTD_COMPRESSION=1 WITH_CHISELDB=0 WITH_CONSTANTIN=0
- 结果：rc=0，产物 XiangShan/build/simv（2.3MB）。

## 6. hello 编译与 Difftest
- 编译：cd nexus-am/apps/hello && make ARCH=riscv64-xs CROSS_COMPILE=riscv64-unknown-elf-
  （arch 默认要 linux-gnu 工具链，服务器只有 elf，命令行覆盖 CROSS_COMPILE）
  产物：build/hello-riscv64-xs.bin (5600B)。
- --no-diff：./simv +workload=.../hello-riscv64-xs.bin +no-diff
  -> Hello, XiangShan! / Core 0: HIT GOOD TRAP at pc = 0x8000014c / DIFFTEST WORKLOAD DONE at cycle 3677。
- --diff：./simv +workload=.../hello-riscv64-xs.bin +diff=$NEMU_HOME/build/riscv64-nemu-interpreter-so
  -> Difftest enabled / Hello, XiangShan! / Core 0: HIT GOOD TRAP at pc=0x8000014c / 零 mismatch，rc=0。
- 结论：阶段一 Difftest 全链路跑通（VCS + NEMU golden，550 条指令零差异）。
