# 端到端量化 MLP 推理加速报告（vmlp）

## 1. 目标

单点 GEMV 只覆盖一个线性层。真实 LLM 推理（FFN、QKV 投影）是"线性层 + 激活"的多层堆叠。本 demo 用 vqdot 实现一个完整的 **2 层量化 MLP 前向**，验证融合点积在端到端网络中的累积收益。

## 2. 网络结构

```
x[16](int8)
  │  W1: 8×16 (int8), b1[8]
  ▼  GEMV（vqdot）
h1[8](int32)
  │  ReLU + 饱和量化
  ▼
h8[8](int8)
  │  W2: 4×8 (int8), b2[4]
  │  GEMV（vqdot）
  ▼
y[4](int32)
```

- 第一层 M=8 = 两个输出块（各 4 输出），每块 N=16 共 4 个 tile；
- 第二层 M=4，N=8 共 2 个 tile；
- 整个网络共 3 次参数化 GEMV（2 次 N=16 + 1 次 N=8）。

## 3. 参数化 kernel

`gemv4_vqdot(Wpacked, x, bias, y, N)`：一个向量固定 4 输出，输入维度 N 作为参数（a4），tile 循环次数随 N 变化。权重离线重排为 `[输出块][tile][16 字节]`，与 vgemv 相同的 4×4 tile 布局。

中间 ReLU/量化只涉及 8 个标量，用标量处理（非点积加速的关键路径）。

## 4. 确定性数据与 golden

- `x[j] = (j%4) - 1`（-1,0,1,2 循环）
- `W1[m][j] = ((m+j)%3) - 1`（-1,0,1），`b1[m] = m`
- `W2[k][m] = (m%3) - 1`，`b2[k] = 10k`

整数 C golden 完整跑 2 层 MLP：

| 量 | 值 |
|---|---|
| 隐藏层（ReLU 后 int8） | 0, 0, 3, 3, 3, 6, 6, 6 |
| 输出 y | **0, 10, 20, 30** |

vqdot 与标准 RVV baseline 两个 kernel 输出均与 golden 完全一致。

## 5. 端到端延迟

整个 2 层 MLP 前向（含 3 次 GEMV、ReLU、量化、所有 load/store），R=20 取平均：

| 实现 | 周期 | 加速比 |
|---|---|---|
| 标准 RVV（vwmul + 加法树 + 置换） | 685 cyc | 1.00x |
| **vqdot 融合点积** | **285 cyc** | **2.40x** |

## 6. 分析

- 单层 GEMV 是 2.82x（INT8），堆叠成 2 层 MLP 后端到端为 2.40x：差距来自 ReLU/量化/层间搬运等非 GEMV 开销（这部分两实现相同、不被加速），网络越深、GEMV 占比越高，端到端加速比越接近单层 GEMV 的值。
- 这说明 vqdot 的收益在真实网络中是可累积的：每经过一个量化线性层就按 GEMV 比例缩短一次，而不是只在微基准里成立。
- 该 MLP 结构可直接推广到 LLM FFN（上投影 GEMV + 激活 + 下投影 GEMV），仅需扩大维度、用 LMUL 处理更长向量。
